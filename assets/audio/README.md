# Recorded Bible audio

`web.json` maps the app's canonical book/chapter references to the provider's
published chapter manifest. It contains 66 books / 1,189 chapters. No audio
recordings are bundled, cached for offline use, or downloaded automatically.
Playback is on demand over HTTPS and requires internet access.

Narrator: David Williams. Recorded in 2000; placed in the public domain by the
narrator in 2016 according to the publisher's recording notice:
https://www.publicdomainaudiobibles.com/WEBD.html

Original chapter manifest:
https://www.publicdomainaudiobibles.com/content/mp3/WEBD/chapters.json

Mapping and a representative audio/mpeg stream were checked 2026-11-07.
The recording is an earlier WEB edition and can differ from the updated WEB
text bundled as an optional download. The app does not claim word-level audio
alignment. This edition difference is shown in Settings → Audio narration.

# BSB

`bsb.json` maps all 66 books / 1,189 chapters to the published Bob Souer
recording index at https://openbible.com/audio/souer/ . Each link was matched
to the bundled canon's book order and chapter counts (2026-11-07).

Recording rights: public domain / CC0 1.0, according to the official notice:
https://bereanbible.com/audio/
https://creativecommons.org/publicdomain/zero/1.0/

The audio streams only on request and needs internet. It is not bundled.
The recording can differ from later revisions of the text. No word-level
synchronization is claimed. The notice is available in Settings → Audio narration.

There is no verified source configured for OCCB, Tagalog ULB or ASV, and none silently
uses the WEB recording. Their reader does not show a Play button. Add sources
only after checking their edition, availability, mapping and recording rights.
