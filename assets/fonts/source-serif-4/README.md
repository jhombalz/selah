# Source Serif 4

Unmodified static TrueType fonts from Adobe's official Source Serif repository.
Regular (400), Bold (700), and Italic (400) are bundled for offline use.
See `provenance.json` for the exact upstream commit and `OFL.txt` for the license.

Source: https://github.com/adobe-fonts/source-serif/tree/release/TTF
Specimen: https://adobe-fonts.github.io/source-serif/

Used for Bible text, chapter headings, search passages, and reading previews.
Navigation controls retain the platform's normal sans-serif typeface.
Font size preferences and line spacing are retained.
