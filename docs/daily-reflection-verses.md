# Daily reflection passages

SELAH v0.6.2 rotates 80 selected Scripture references for reflection and memory.
They include well-known passages about faith, love, prayer, wisdom, courage,
hope and following Jesus. This replaces unrestricted random draws, which could
select genealogies or fragments that are difficult to use as daily memory verses.

The device's local calendar date determines the reference. It stays the same
throughout the day, changes at midnight, and does not repeat during the 80-day
cycle for a complete Bible. The collection works offline and needs no random
verse API. Legacy daily random choices are replaced, including today's cache.

Scripture wording always comes from the selected translation. NIV/NLT still need
internet for uncached or expired chapters; their existing cache rules apply.
Read in context opens the surrounding chapter in the Bible tab. A familiar
passage should still be read in its original setting, not treated as a personal
promise detached from its context.
